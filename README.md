# Emoji Word Combination Game

A fun and interactive web-based game where players combine emojis to form words. Test your vocabulary and emoji interpretation skills!

## 🎯 About the Game

Combine two emojis to guess the hidden word! Each correct answer earns you points and brings you closer to becoming an Emoji Master. But be careful - one wrong answer and it's game over!

**Features:**
- 🎮 15 challenging emoji combinations
- 📊 Progressive scoring system
- 🏆 Ranking system (Beginner → Master)
- 📱 Fully responsive design
- 🎨 Beautiful gradient UI

## 🚀 How to Play

1. Look at the two emojis displayed
2. Think of a word that combines their meanings
3. Type your answer in the input box
4. Press Enter or click "Check Answer"
5. Score points for correct answers!
6. Advance to the next level

## 🎮 Game Rules

- You start with 1 life (❤️)
- Each correct answer: +10 points
- Wrong answer: Game Over 💔
- Complete all 15 words to win!
